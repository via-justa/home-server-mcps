# Admin portal mockups

The UI mockups the admin portal was built from (design §8): Connection, Methods, Pre-Approval Rules, Pending Approvals and Audit Log. The design doc cites them as a visual reference; the portal in `packages/admin-ui` is the source of truth.

The `.dc.html` files are Claude "Design Component" sources. Each describes one screen but expects a small runtime from the artifact host, so opening one directly in a browser won't render it correctly. Read the markup and inline styles as a spec, or paste a file into a new Claude Design artifact to re-render it. `canvas.json` is the layout index of the original multi-artboard canvas and isn't needed to read the individual files.
